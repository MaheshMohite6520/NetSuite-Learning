# Week 23 – Multi-Currency & Revaluation in NetSuite

## Overview

This week focuses on taking a **deep dive into NetSuite's Multi-Currency and Foreign Currency Revaluation Architecture**, exploring how organizations manage transactions across multiple currencies, maintain exchange rates, perform period-end revaluations, consolidate financial statements, and automate currency operations using SuiteScript.

Multi-currency accounting is one of the most important capabilities in global ERP implementations.

It is far more than allowing transactions in different currencies.

It is a complete financial architecture connecting:

- Base Currency
- Foreign Currency
- Transaction Currency
- Multiple Currencies
- Currency Records
- Currency Exchange Rates
- Exchange Rate Integration
- Foreign Currency Revaluation
- Realized Gain/Loss
- Unrealized Gain/Loss
- Currency Revaluation Transactions
- Consolidated Exchange Rates
- Budget Exchange Rates
- OneWorld Multi-Subsidiary Currency Management
- Month-End Currency Revaluation
- General Ledger Integration
- Financial Reporting
- Consolidated Financial Statements
- Currency Translation
- Multi-Book Accounting
- SuiteScript Currency APIs
- Currency Record Scriptability
- Scheduled Script Automation
- Financial Governance

Every foreign currency transaction ultimately impacts financial reporting.

Whether the transaction originates from:

- Sales Orders
- Invoices
- Cash Sales
- Purchase Orders
- Vendor Bills
- Customer Payments
- Vendor Payments
- Credit Memos
- Journal Entries
- Bank Transactions
- Credit Card Transactions
- Intercompany Transactions
- Multi-Subsidiary Operations
- International Sales
- Global Procurement

the organization must ultimately answer one critical question:

> Which exchange rate should be applied, and how should currency fluctuations be reflected accurately in the financial statements?

Because multi-currency accounting is never determined by a single exchange rate.

It depends on base currencies, transaction currencies, exchange rate tables, accounting periods, foreign currency revaluation, consolidated exchange rates, subsidiary structures, and financial reporting requirements.
